# Security policy

Report suspected vulnerabilities privately through GitHub's security advisory
workflow for `zephytiju/meridian-storage-semantics`. Do not disclose credentials,
tokens, exploit details, or affected private data in a public issue.

Version 1.x receives security fixes. Release artifacts are reproducibly built,
SHA-256 hashed, accompanied by an SPDX SBOM, and covered by GitHub provenance
attestations. Verify the tag, release hashes, and attestation before deployment.
