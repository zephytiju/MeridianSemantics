# Meridian Storage Semantics

`meridian-storage-semantics` is the independently released Meridian V1 logical
schema, resource, data, and semantic-profile package. It integrates with the
released `meridian-storage-core` contract and owns only the `structured` and
`cache` Catalog surfaces.

The implementation is being delivered through the scoped 02m-02 pull request.
This public repository was created empty and public before its first commit.
